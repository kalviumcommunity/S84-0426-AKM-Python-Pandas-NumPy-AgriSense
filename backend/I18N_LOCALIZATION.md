# Internationalization (i18n) Support

## Supported Languages
- English (en-US)
- Hindi (hi-IN)
- Punjabi (pa-IN)
- Marathi (mr-IN)
- Tamil (ta-IN)

## Implementation
- Flask-Babel for backend translations
- JSON translation files per language
- Accept-Language header detection
- User language preference storage

## Localized Content
- API error messages
- Email templates
- SMS notifications
- Crop names and descriptions

## Regional Formats
- Date/time formats (DD/MM/YYYY for India)
- Currency ( symbol, Indian numbering)
- Temperature units (Celsius)
- Measurement units (hectares, quintals)

## Translation Workflow
- Extract strings with pybabel
- Crowdin for community translations
- Automated translation updates
